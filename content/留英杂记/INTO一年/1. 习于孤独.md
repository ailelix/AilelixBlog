熟悉的CZ673，熟悉的希思罗机场
熟悉的Euston to Manchester Piccadilly，摇摇晃晃的列车
Lofi、sparkling water、窗外的雨、大雾和平原

不知不觉已经gap了一年有余

下火车 熟悉的站台 蒙蒙细雨 熟悉的光景
从去年初见时的兴奋 到再见时的平常

穿过喧闹的车站 拖着巨大的行李箱 到达宿舍门前
一切都那么的如梦似影 却又真实存于眼前

# NEET
不得不说，这一年是相当懈怠的
但无论如何 也是从痛苦中走了出来

懈怠之余，是蜗居和无所事事
偶尔的社交活动 沉浸于孤单之中

在经历过百日的隔离摧残后
这一年竟也平淡过来了

本以为这平淡中的半社交半孤单
已是相当的难过
可未曾想到
到了英国的留学生活
会甚之一番

# Rainy
气候会在不知不觉中影响心境
连绵的阴暗、时不时的雨
无不压抑着空气

不爱甜食的习惯也大大减少了多巴胺
几者加之，本就是略微抑郁的气氛

# Flatmates
五人舍，公用厨房，独立卫浴，隔音一般
虽然称不上最理想的舍友
但我确实不能要求更高

不同的性格、不同的文化、不同的想法
虽然酩酊时能称兄道弟
但毕竟不是交心的知己

最多最多，也就是做饭时闲聊两句，抱怨一二
在学校碰到了，打个招呼、寒暄一二
姑且是一年的舍友，点头之交罢了

# New Friends
虽是走班制，但也结识了几个朋友
有一起上课，但也仅限至此的
有兴趣相投，但也无非蹭饭之交的

我并不擅长，也不喜欢参加那些社交
每次那些小团体一起聊天时
我也只是在一旁忙着自己的事

列表无非那几个 也不甚联系
也可以说，这是我咎由自取吧

# Old days
为数不多的慰藉
来自每天TeamSpeak频道老友的声音
和一条条的消息气泡

然而
地理上的遥远，隔绝了太多
无论是宏观上数小时的时差
还是游戏时几百毫秒的延迟

况且
虚拟的沟通，只是安慰剂罢了
每次下线后的空虚，反使得孤独加之
但又不得不沉浸于这虚幻之中
像是成瘾一般，贪婪于每天那两小时中
愈得愈失

# Home
本身为了逃离而远离
自然是不会太多联系的

对话大多不由我这一侧发起
一个月唯二通话也是父母生日

他们并不理解，而我也理解这点
所以并不联系，也借以忙碌推脱

这种情绪的确是极其复杂的
一方面，抵触着、厌烦着
另一方面，担心着、牵挂着
但终究是选择了沉默

# Jealous
有无能交心之人仅仅是一方面的
寂寞时不时会以另一种方式出现
打个措手不及

无论是
上课，撇到两人不同班却同时摸鱼聊天

还是
路上，看见一对卿卿我我、有说有笑

心里会被轻轻戳一下，轻轻叹气

确实是相当的反常
上次如此悸动，还是几年前的自我意识过剩
这三年来，内心是相当平淡，冷漠的
却突然变得瘙痒、渴求
但也只能隔靴抓挠

# Pathetic
有时，烦躁和孤单刀绞心尖
抱着被子抽泣，憋着不出声音
哭完了，耳机放一段全肯定音声
去盛一杯干涩的金酒
回到电脑前忙于作业
更甚之
打开LM-Studio
和`llama-3.2-8b`倾诉两句
> So pathetic.

是啊
这也是为何我自嘲哥布林
So pathetic.

我花了六年时间
从内向试探出来
虽不说变得外向
但多少是能不在台上颤抖了
然而这一过程并不舒服

现在
这颗渴求的心
正在习于孤独
